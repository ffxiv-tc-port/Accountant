# Accountant

追蹤各種有時效性的遊戲內事務，統一顯示倒數計時，並在到期前提醒。

## 功能

- **僱員**：派遣中的委託任務剩餘時間，到期提醒。
- **飛艇 / 潛水艇**：船塢派遣航程剩餘時間，到期提醒。
- **乙太之輪**：公會乙太之輪剩餘時間。
- **花圃**：房屋庭院與室內盆栽的作物成長進度，可依擁有者或作物種類排序檢視。
- **委託**：每週委託次數剩餘與重置時間。
- **冒險者分隊**：任務進度與剩餘時間。
- **藏寶圖判讀次數**：每週判讀次數剩餘與重置時間。
- **仙人微彩 / 仙人仙彩**：每日、每週開獎倒數。
- **客戶委託**：每週配送次數剩餘與重置時間。
- **友好部族任務**：每日可承接任務數。
- **房屋拆除警告**：即將被拆除的房屋提前提醒。
- **伺服器資訊列**：可將花圃、僱員、飛艇、潛水艇等計時器顯示在伺服器資訊列。
- 可依公會分別記錄與顯示上述資料。

## 指令

- `/accountant`：開啟設定視窗；加上 `timers` 參數（`/accountant timers`）可切換計時器視窗開關。
- `/acct`：切換計時器視窗開關。
