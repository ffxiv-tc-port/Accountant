# Accountant

[Accountant](https://github.com/Ottermandias/Accountant) 的台服移植版。追蹤各種有時效性的遊戲內事務，統一顯示倒數計時，並在到期前提醒。

## 功能

- **僱員**：派遣中的探險剩餘時間，到期提醒。
- **飛空艇 / 潛水艇**：探索航程剩餘時間，到期提醒。
- **乙太轉輪**：公會乙太轉輪剩餘時間。
- **作物**：房屋庭院與室內盆栽的作物成長進度（生長中、凋萎、枯萎等），可依擁有者或作物種類分組檢視。
- **理符任務**：理符任務次數（每 12 小時恢復 3 次、上限 100），接近上限時提醒。
- **冒險者分隊**：分隊任務與分隊訓練的剩餘時間。
- **寶物地圖解讀次數**：下次可以解讀的時間。
- **仙人微彩 / 仙人仙彩**：每日、每週的購買與開獎狀況。
- **老主顧交易**：每週交易次數剩餘。
- **友好部族任務**：每日可承接任務數。
- **房屋自動拆除警告**：太久沒進入的房屋，在自動拆除前提前提醒。
- **伺服器資訊列**：顯示僱員、飛空艇／潛水艇與作物的狀態；左鍵開關計時視窗，右鍵開關設定視窗。
- 可依公會分別記錄與顯示上述資料。
- 遊戲改版後某些位址對不上時，插件照常載入，只有對應的計時器暫停更新，並在設定視窗最上方寫明是哪幾項。

## 指令

- `/accountant`：開啟設定視窗；加上 `timers` 參數（`/accountant timers`）可切換計時器視窗開關。
- `/acct`：切換計時器視窗開關。

## 台服版的修改

- 介面繁體中文化，作物與乙太轉輪的偵測改用台服的資料。
- 選用 AutoRetainer：沒派探險的僱員改向 AutoRetainer 讀資料。
- 遊戲改版後特徵碼對不上時不再整個插件載入失敗。
- 公會資料與房屋拆除追蹤的檔案一時讀不進來時，不再清空已記錄的資料。
- 伺服器資訊列左右鍵統一：左鍵計時視窗、右鍵設定視窗。
- 多處降低記憶體用量。
